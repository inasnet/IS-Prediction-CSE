# Archive des scripts Python

Le dossier principal conserve uniquement les sept programmes décrits dans le
rapport hebdomadaire 3 :

1. `01_find_company_websites.py`
2. `02_download_reports.py`
3. `03_extract_financials.py`
4. `04_build_dataset.py`
5. `05_audit_coverage.py`
6. `06_clean_manifest.py`
7. `07_extract_all.py`

Le fichier `scripts_apres_rapport_3.zip` contient les 114 scripts intermédiaires
créés après ce rapport : validation, nettoyage, statistiques, modélisation,
prévisions et intégrations historiques.

Cette archive permet de restaurer intégralement le code détaillé si une étape
doit être reproduite ou auditée. Elle ne contient pas les données ni les
rapports PDF, qui restent à leur emplacement actuel.
